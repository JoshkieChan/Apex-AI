# Changelog

## 1.0.0rc1

Release candidate for Apex AI v1.0. This is not a published GitHub release.

The candidate includes the runtime, identity, approvals, memory, coordination, worker recovery, multimodal interaction within the implemented formats, and governed connections from the preceding milestones. Schema revision `0009_controls` adds an operator execution hold. A disposable PostgreSQL dump and restore is part of the deployment check.

Live OpenAI, Anthropic, Vault, OIDC, and third-party accounts are not part of the tested path. A2A is not implemented. The supported deployment is one API process and one worker.
