# Apex AI v1.0 release candidate

Version `1.0.0rc1` is the release candidate. It is not a published GitHub release and it is not a production deployment. Those stay with the operator.

The supported runtime is Python 3.12, one API process, one worker, and PostgreSQL 16. Schema revision is `0009_controls`. The image runs as `nobody`. Development token issuance is off when `APEX_ENVIRONMENT=production`.

## Capability matrix

| Capability | Class | What v1.0 includes |
| --- | --- | --- |
| Task lifecycle, registry, execution, verification | Supported | Mock provider and deterministic checks |
| RS256 bearer identity, grants, delegation, approval | Supported | Production refuses development signing |
| Governed memory and context | Supported | Model text stays an inferred candidate |
| Goal coordination and one worker | Supported | One worker. Horizontal scaling is unsupported |
| Remote MCP with dispatch certainty | Limited | In-process fixture is tested. A paid remote server was not called |
| Reference API and reference device | Supported | In-process allowlist. No generic HTTP tool |
| Text, PNG, JPEG, WebP, WAV, MPEG-1 Layer III | Limited | Mock provider in CI. Live perception was not called |
| OpenAI and Anthropic adapters | Limited | Mocked HTTP. No silent fallback |
| Vault and OIDC | Limited | Mocked clients. No live server in this repository |
| Execution hold | Supported | Stops new attempts. Does not replay uncertain work |
| Backup and restore | Limited | Disposable dump/restore is tested. Operator backups are not taken by the app |
| A2A, marketplace, video, duplex voice, Kubernetes | Future | Not in this candidate |

## Release checklist

- [x] `ruff check`, `ruff format --check`, and `mypy` pass.
- [x] `pytest` with PostgreSQL passes.
- [x] `python -m tests.integration.deployment_probe` prints `deployment-ok`.
- [x] `python -m tests.integration.backup_restore` prints `backup-restore-ok`.
- [ ] GitHub Actions is green on the candidate commit.
- [ ] The operator has an encrypted copy of a database dump and has read `docs/operations/runbooks.md`.
- [ ] The operator confirms production identity and secret-provider settings. The repository does not contain them.
- [ ] The operator explicitly chooses to publish or deploy. This candidate does not do that.

## Rollback

Stop the API and the worker. Start the previous image only against a database whose Alembic revision that image understands, or restore the dump taken before the upgrade into a new volume and point the previous image at it. Do not run a newer `alembic upgrade` if you intend to go back. Downgrade is implemented in Alembic and is exercised by the migration test. A downgrade drops tables added by that revision. It does not restore rows that the upgrade discarded. Prefer the dump.
